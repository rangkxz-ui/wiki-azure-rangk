# Orden de páginas con .order

Azure DevOps ordena las páginas alfabéticamente, salvo que haya un archivo `.order` en la carpeta. Contiene un nombre de página por línea, sin extensión:

```text
Inicio
Guia-de-instalacion
Arquitectura
```

Las páginas que no aparezcan en `.order` se muestran después, en orden alfabético.
