# Code Wiki

Publica archivos Markdown que **ya existen** en un repositorio (o en una carpeta de él).

- La documentación viaja junto al código: mismas ramas, mismos pull requests, misma revisión.
- Puedes publicar varias, una por repositorio o rama.
- Ideal para que la documentación no se quede atrás cuando el código cambia.

**Úsala para:** READMEs, referencias de API, arquitectura y guías de desarrollo.
