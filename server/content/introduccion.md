# Qué es una wiki de Azure DevOps

Una wiki de Azure DevOps es un espacio de documentación escrito en **Markdown** y ligado a un proyecto. Sirve para que el equipo comparta guías, decisiones y conocimiento técnico en un solo lugar.

Existen dos tipos:

| Tipo | Dónde vive el contenido | Cuántas por proyecto |
|---|---|---|
| Project Wiki | Repositorio Git oculto del proyecto | Una |
| Code Wiki | Una carpeta de un repositorio existente | Varias |

Ambas guardan el historial de cambios, permiten búsqueda y se pueden enlazar con elementos de trabajo.
