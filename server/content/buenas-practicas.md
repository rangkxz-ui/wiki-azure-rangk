# Buenas prácticas

1. **Una página, un tema.** Es más fácil de encontrar y de actualizar.
2. **Títulos descriptivos.** Prefiere "Cómo desplegar en producción" a "Deploy".
3. **Enlaza en vez de copiar.** Evita información duplicada que se desactualiza.
4. **Usa Code Wiki para lo técnico** y Project Wiki para lo organizativo.
5. **Revisa de vez en cuando.** Elimina o actualiza las páginas obsoletas.
