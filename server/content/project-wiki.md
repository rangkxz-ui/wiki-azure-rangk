# Project Wiki

Se crea desde **Overview > Wiki** y Azure DevOps la provisiona sola.

- Se guarda en un repositorio Git oculto, por lo que puedes **clonarla y editarla en local**.
- Solo hay una por proyecto.
- Edición directa en el navegador, sin pull requests.

**Úsala para:** guías de incorporación, procesos del equipo, notas de reuniones y decisiones.
